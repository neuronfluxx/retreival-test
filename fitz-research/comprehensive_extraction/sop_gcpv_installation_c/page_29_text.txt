Since Assam is in the very high damage risk wind zone, the mid-clamps used for attaching the 
modules must be longer than 50mm (2 inches) in length and it is recommended to use 3 rails 
while installing in portrait position. In a large system, consideration shall be given for using 
an end clamp for every fourth module so if one does become loose, then only a few other 
modules would be affected, not necessarily the whole array.
