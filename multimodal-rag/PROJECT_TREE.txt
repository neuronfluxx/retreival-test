🚀 Quick Start Commands
═══════════════════════════════════════════════════════════════

Install:
  pip install -r requirements.txt

Validate:
  python validate_setup.py

Run:
  make run
  # or
  uvicorn app.main:app --host 0.0.0.0 --port 8003 --reload

Test:
  make test
  # or
  pytest tests/ -v --cov=app

Docker:
  docker-compose up -d

Format:
  make format

Clean:
  make clean


📡 API Endpoints
═══════════════════════════════════════════════════════════════

Health:
  GET  /health                    - Health check
  GET  /ready                     - Readiness probe
  GET  /metrics                   - Prometheus metrics

Documents:
  POST   /api/v1/documents/upload           - Upload document
  GET    /api/v1/documents/collections      - List collections
  DELETE /api/v1/documents/collections/{id} - Delete collection

Query & Search:
  POST /api/v1/query              - RAG query (with generation)
  POST /api/v1/search             - Similarity search
  POST /api/v1/search/multimodal  - Hybrid search

Documentation:
  GET  /docs                      - Swagger UI
  GET  /redoc                     - ReDoc UI
